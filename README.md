# Sweet Slice – Cake Recipe Book

A PHP website that reads cake recipes from `recipes.txt` and shows them in a dropdown with photo and numbered steps.

## How it works
- `#` starts a cake name, `*` gives its photo, and all other lines are the recipe text.
- Adding a new recipe to `recipes.txt` makes it appear automatically.

## Run locally
Put the folder in `C:\xampp\htdocs\`, start Apache in XAMPP, and open `http://localhost/CakeRecipeBook/index.php`.

## Features
Gallery, previous/next/random buttons, dark mode, tick-off steps, print view.
